# Логотип DV Photo Validator

Белые уголки рамки кадрирования, силуэт человека и зелёная галочка «проверено» на синем фоне. Синий `#1A5FB4` — основной цвет интерфейса приложения.

| Файл | Назначение |
|---|---|
| `logo.svg` | Исходник (512×512) |
| `logo-1024.png`, `logo-512.png`, `logo-256.png`, `logo-64.png` | Растровые версии (README, магазины приложений) |
| `src/DvPhotoValidator.App/Resources/app.ico` | Иконка Windows: exe и окно (16–256 px) |

Все файлы генерируются из одного описания фигур в `generator/Program.cs`. После изменения логотипа запустите генератор и скопируйте результаты на места из таблицы:

```bash
dotnet run --project branding/generator -- out
```

| Цвет | Значение |
|---|---|
| Синий (основной) | `#1A5FB4` |
| Синий светлый (градиент) | `#2F7FE0` |
| Зелёный (галочка) | `#2EB872` |
